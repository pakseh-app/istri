# Wulan Agustina — Surat Ulang Tahun

Versi FULL dengan animasi amplop dan surat. Perbaikan terbaru membuat bagian atas kertas tetap terlihat pada layar HP maupun laptop dengan tinggi layar pendek.

## Struktur

- `index.html` — halaman utama
- `style.css` — desain dan animasi
- `script.js` — interaksi buka surat dan musik
- `foto/wulan-agustina.jpg` — masukkan foto Wulan
- `music/lagu.mp3` — masukkan musik pilihanmu

## GitHub

Hapus file versi lama di repository, lalu upload seluruh isi folder ini.

Foto harus bernama `wulan-agustina.jpg` dan musik harus bernama `lagu.mp3`.

Pada HP, jika surat lebih tinggi daripada layar, halaman dapat digulir ke bawah. Bagian atas surat tidak lagi diposisikan di luar viewport.


## Folder amplop
Folder `amplop/` berisi `amplop-kosong.png`. Ganti file tersebut dengan desain amplop lain jika diperlukan. Semua teks halaman pembuka tetap ditulis di `index.html` sebagai HTML overlay.
