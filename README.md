# Wulan Agustina — Surat Ulang Tahun 💌

Ini adalah **versi full/utuh** website. Kamu bisa membersihkan repository GitHub lama lalu upload seluruh isi folder ini.

## Struktur

```text
index.html
style.css
script.js
README.md
foto/
├── README.txt
├── .gitkeep
└── wulan-agustina.jpg   ← masukkan foto Wulan di sini
music/
├── README.txt
├── .gitkeep
└── lagu.mp3             ← masukkan musik pilihanmu di sini
```

## Cara memasang di GitHub

1. Hapus file versi lama dari repository jika ingin benar-benar bersih.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, folder `foto/`, dan folder `music/` dari paket ini.
3. Masukkan foto Wulan dengan nama **`wulan-agustina.jpg`** ke folder `foto/`.
4. Masukkan musik pilihanmu dengan nama **`lagu.mp3`** ke folder `music/`.
5. Aktifkan GitHub Pages pada repository tersebut.

## Alur website

- Halaman awal menampilkan **Selamat Ulang Tahun, Wulan Agustina ♥**.
- Tekan **Buka ♥**.
- Amplop terbuka dengan animasi.
- Kertas surat keluar dan terbuka.
- Doa dan ucapan muncul di atas kertas.
- Love/gelembung dan sparkle berada di **layer paling depan**, termasuk pada layar HP.
- Musik dapat diputar melalui tombol musik dan file musik bisa diganti tanpa mengubah kode.

Nama dan isi surat tidak berasal dari input pengunjung, sehingga pengunjung tidak dapat mengganti nama atau foto melalui halaman.
